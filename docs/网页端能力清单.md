# 网页端能力清单（数据中心）

## 定位

手机端是"现场作业端"：局域网离线连接无人机、执行航线、机载处理、本机保留 7 天。
网页端是"归档与分发端"：同步过往巡检数据（后端具备同步全部数据的能力），供检索查看、下载导出与数据分析。
两端通过**同步码**衔接：每次巡检一个码，手机端生成，网页端凭码拉取。

## 四个模块

### 1. 同步数据
- 输入同步码：`UAV-XXXX-XXXX`，不区分大小写，容错空格与全角连字符；弹窗支持批量粘贴
- 同步全部：一键拉取手机端 / 机载端所有尚未同步的任务（后端全量同步能力的入口）
- 同步记录：时间、来源设备、数据包大小、完整性（按附件清单逐项校验 MD5）；缺失附件可重新生成同步码补传

### 2. 任务数据
- 搜索：任务编号 / 同步码 / 航线 / 场景 / 操作员；筛选：状态、场景
- 列表：巡检时间、任务与同步码、场景航线、状态、覆盖、结果、异常
- 任务详情
  - 概览：核心指标（体积或件数、覆盖度、体积误差、定位精度、时长、处理状态）+ 三维成果 + 同步信息 + 堆体/货位明细（行点击与三维联动）
  - 三维成果：点云 + 航线 + 轨迹 + 包围框，顶视/全景、图层、全屏；右下角实测加载耗时与帧率
  - 飞行过程：电量/速度/高度曲线（标注停障与返航）、航点时间线、飞行事件、机载处理阶段
  - 报告：A4 在线预览，打印 / 下载 PDF，与手机端 PDF 一致
  - 附件下载：PCD / JSON / PDF / CSV / MP4 / 图片 ZIP，大小与 MD5，单个 / 所选 / 全部打包

### 3. 数据分析
- 同一航线多次巡检：合计与各堆体体积随时间曲线
- 相邻两次差值（入库为正、出库为负），提示测算误差带
- 异常变化：单堆体相邻变化 ≥ 12% 列出，可跳转任务复核

### 4. 下载导出
- 队列：排队 / 打包中 / 下载中进度
- 记录：文件、任务、大小、下载人、时间；可再次下载；保留 180 天供审计
- 批量：任务数据页勾选多任务打包下载

## 非功能

- 三维查看：稀疏点云在线预览，加载 ≤ 10 s，交互 ≥ 30 FPS（页面右下角实测）
- 浏览器：Chrome / Edge 110 及以上，WebGL 2
- 部署：静态前端 + REST 后端；本原型为纯前端 mock，数据在内存中
