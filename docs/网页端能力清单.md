# 网页端能力清单（数据中心）

## 定位

手机端是"现场作业端"：局域网离线连接无人机、执行航线、机载处理、本机保留 7 天。
网页端是"归档与分发端"：跨网络长期保存过往巡检数据，供管理、账务、验收人员检索、查看与下载。
两端通过**同步码**衔接：每次巡检一个码，手机端生成，网页端接入。

## 用户与场景

| 角色 | 典型诉求 |
|------|----------|
| 仓储管理员 / 账务 | 定期看库存体积变化，下载报告归档，交给上级或审计 |
| 运维 / 操作员 | 回看飞行过程（轨迹、遥测、事件），排查中断与异常 |
| 甲方验收 / 领导 | 看三维成果与报告，下载 PDF；不关心原始点云 |

## 能力模块

### 1. 接入与同步
- 同步码接入：`UAV-XXXX-XXXX`，不区分大小写，容错空格与全角连字符；支持批量粘贴
- 校验与拉取：格式校验 → 有效期校验（7 天）→ 从手机端 / 机载端拉取数据包
- 同步记录：同步时间、来源设备、数据包大小、完整性（按附件清单逐项校验 MD5）
- 缺失补传：附件缺失时在详情页标出，手机端重新生成同步码后补传

### 2. 任务库（检索）
- 搜索：同步码 / 任务编号 / 航线 / 场景 / 设备 / 操作员 / 货物标签编码
- 筛选：状态、场景、货物类型（散料 / 码垛）、时间范围、仅看有异常
- 排序：时间 / 体积 / 覆盖度
- 批量：勾选多任务打包下载
- 概览：已接入任务数、累计体积、数据包总量、附件不完整数

### 3. 任务详情
- 概览：合计体积或件数、覆盖度、体积误差、定位精度、飞行时长、处理状态、接入信息
- 三维成果：点云 + 航线 + 轨迹 + 堆体包围框 + 标签，顶视 / 全景，图层开关，全屏；点击堆体联动明细；显示加载耗时与帧率
- 飞行过程：起降时间、航点完成、返航触发、电量消耗；电量 / 速度 / 高度曲线（标注停障与返航）；航点时间线（到达时刻、拍照、悬停）；飞行事件；机载处理阶段
- 明细：堆体 / 货位表（体积、分层件数、标签识别、表面覆盖、置信度、异常、遮挡说明）
- 报告：A4 在线预览，打印 / 下载 PDF，内容与手机端 PDF 一致
- 附件：三维模型 PCD、体积结果 JSON、盘点汇总 JSON、报告 PDF、遥测 CSV、事件 JSON、视频 MP4、点位图片 ZIP；大小、MD5、单个 / 所选 / 全部打包下载

### 4. 库存趋势
- 同一航线 2 次以上完成巡检 → 合计与各堆体体积随时间曲线
- 相邻两次差值（入库为正、出库为负），并提示误差带
- 异常变化：单堆体相邻变化 ≥ 12% 列出，跳转对应任务复核

### 5. 下载中心
- 队列：排队 / 打包中 / 下载中进度
- 记录：文件、任务、大小、下载人、时间；可再次下载；保留 180 天供审计

### 6. 档案
- 设备：巡检次数、累计飞行、数据量、最近任务
- 航线：场景、扫描方式、航点、高度、离堆、录制信息、已接入巡检次数、最近体积
- 场景：点云地图版本、建图时间、航线数、已接入巡检

### 7. 设置
- 账号与角色（管理员 / 查看者权限差异）
- 数据策略（同步码有效期 7 天、归档 90 天、下载记录 180 天、容重）
- 部署与集成（私有化 / SaaS、与手机端分工、REST 接口、导出格式）
- 关于（版本、适配手机端版本、浏览器要求）

## 与手机端的对应关系

| 手机端 | 网页端 |
|--------|--------|
| 巡检结果 → 结果报告 → 同步到网页端（复制同步码） | 接入同步码 |
| 巡检数据列表（本机 7 天） | 任务库（归档 90 天） |
| 成果详情：三维 / 过程 / 结果 | 任务详情：三维成果 / 飞行过程 / 明细 |
| 报告预览 → 保存到手机 | 报告在线预览 → 打印 / 下载 PDF |
| 附件清单（导出到下载目录） | 附件：单个 / 打包下载，MD5 校验 |
| 无 | 库存趋势、下载中心、档案 |

## 非功能

- 三维查看：稀疏点云在线预览，加载 ≤ 10 s，交互 ≥ 30 FPS（页面右下角实测）
- 浏览器：Chrome / Edge 110 及以上，WebGL 2
- 部署：静态前端 + REST 后端；本原型为纯前端 mock，数据在内存中
